# Интеграционное тестирование (Integration Tests)

Данный уровень проверяет взаимодействие ключевых модулей библиотеки между собой, верифицируя "жизненный цикл данных" внутри системы.

## 1. Взаимодействие базовых механизмов

### Сценарий "Замкнутый цикл" (Circle of Life)
*   **Цепочка:** `Scheduler` -> `TablePool` -> `EventDispatcher` -> `Subscriber` -> `TablePool`.
*   **Что проверяем:**
    1.  Планировщик запускает периодическую задачу.
    2.  Задача запрашивает свободную таблицу из пула.
    3.  Задача генерирует событие, передавая таблицу как данные.
    4.  Диспетчер доставляет событие подписчику.
    5.  Подписчик обрабатывает данные и возвращает таблицу обратно в пул.
*   **Цель:** Проверка отсутствия утечек памяти и рассинхронизации при многократном повторении полного цикла работы системы.

### Сценарий "Каскадные реакции"
*   **Что проверяем:** Цепочки событий, когда реакция одного модуля порождает событие для другого (Cross-module communication).
*   **Цель:** Убедиться, что модули правильно взаимодействуют через шину событий без прямого связывания (Decoupling).

## 2. Целостность данных и Гонки (Race Conditions)

### Сценарий "Удаление во время обработки"
*   **Что проверяем:** Попытка уничтожить монитор ровно в тот момент, когда в очереди диспетчера еще находятся события, сгенерированные этим монитором.
*   **Цель:** Проверка безопасности ссылок (nil-checks) и того, что система не падает при попытке доставить событие от уже несуществующего источника.

### Сценарий "Конкуренция за Пул"
*   **Что проверяем:** Одновременный захват и возврат таблиц из разных типов задач (планировщик, обработчики событий, внешние API).
*   **Цель:** Верификация стабильности реестра пулов при высокой интенсивности операций.

## 3. Инициализация и Сборка

### Полная инициализация (Init Check)
*   **Что проверяем:** Загрузка всей библиотеки через единую точку входа `init_monitor.lua`.
*   **Цель:** Верификация того, что все 27+ внутренних модулей корректно регистрируются, разрешают свои зависимости и инициализируют свои фоновые задачи (таймеры, очереди).
