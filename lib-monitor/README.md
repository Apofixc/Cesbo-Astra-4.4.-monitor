# lib-monitor

`lib-monitor` — это высокопроизводительная библиотека Lua для Astra (Cesbo), предназначенная для глубокого мониторинга DVB-тюнеров, потоков каналов и системных ресурсов.

Библиотека предоставляет программный интерфейс для автоматизации внутри Astra и полноценный HTTP REST API для интеграции с внешними панелями управления и системами мониторинга (Zabbix, Grafana и др.).

## Статус проекта
*   **Версия библиотеки**: 2.6.1
*   **Версия API**: 1.2.0
*   **Статус тестов**: 100% PASS (20/20 модулей + Full Ultra-Extreme Suite)
*   **Требуемая версия Astra**: 4.4.182+

## Быстрый старт

```lua
-- 1. Подключение
local init = require("init_monitor")

-- 2. Запуск API сервера
server_start("0.0.0.0", 8080)

-- 3. Запуск мониторинга канала
make_stream({
    name = "Discovery",
    input = { "http://example.com/stream.ts" },
    monitor = { type = "output" }
})
```

Подробные инструкции см. в разделе **[Установка и быстрый старт](readme/09_installation.md)**.
